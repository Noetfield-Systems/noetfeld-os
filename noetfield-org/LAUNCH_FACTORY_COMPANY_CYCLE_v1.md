# NOOS — Launch Factory Company OS compatibility route
**CANONICAL FACTORY:** https://github.com/Noetfield-Systems/Launch-Factory-Engine

The centralized Factory owns its own product, plans, launch experiments, 28-repo inventory, project Manifest, wave selection, shared distribution, workflow operator, tests, and proof. NOOS does not implement those duplicated capabilities. This NOOS repository owns only the **Noetfield Systems Inc. company-scoped** runtime, existing N-01–N-08 workforce, Governor authority and actual runner integration.

### Locally retained compatibility paths
`scripts/launch_factory_company_cycle_v1.py` and `data/launch-factory-company-cycle-v1.json` are the integration edge for Noetfield-owned company WorkPackets. Their canonical design and regression tests are copied into `Launch-Factory-Engine/scripts/`, `data/` and `tests/`. They are NOT a second Factory orchestration engine or a production claim.

ARQANT, Cairn and BuildRelay remain independent ventures and cannot inherit this corporate NOOS authority. Product-specific Company OS must apply the project owner and actual permits.

### Operational path
Factory GitHub Action / CLI → Founder OS Goalkeeper/project scope → company-specific WorkPacket candidate → existing NOOS auth/workforce/Runway if that company is Noetfield → actual CI/deploy/payment/onchain verification → aggregate Factory report. A Factory plan or GitHub dispatch ACK is not Company OS execution.
